**Scope:** Python client for the *owner-managed*, unchanged Mac mini ESP-01 CH340 UART. No part of this code is included in the ESP8266 or STM32 firmware image. No test in this directory contacts a physical UART.

- `serial_policy.py` — performs the CH340 by-id check, requests DTR/RTS deasserted **before** the pyserial open, and clears Linux `HUPCL` on the **opened tty file descriptor** using `termios`, checking the result before allowing normal operation. It does not issue any reset, Flash operation or system-wide `stty` command. The kernel's exact electrical transitions at an initial open are **not proven** by these software-only tests.
- `node_link_smoke_v2.py` — self-contained frozen Node Link REV2 115200/8N1 frame encoder/parser, fresh unpredictable 32-bit HELLO challenge, exact type/sequence/session/CRC correlation, one permitted retry for HELLO/PING/GET_STATUS, CRC32 DEUS and duplicate-idempotence/STATUS checks. **Without `--execute`, does not open a device.** Only a separate explicit owner-authorized physical task may invoke the device-opening option.
- `test_serial_policy.py` — 6 unit tests using mocked file descriptors, terminal attributes and a fake serial API.
- `test_node_link_smoke_v2.py` — 7 unit tests using an in-memory Node Link endpoint: CRC16 known vector, frame decoding/CRC rejection, all five operations, noise/stale-frame resynchronization, byte-identical HELLO retry, corrupted result rejection, no implicit serial open.
